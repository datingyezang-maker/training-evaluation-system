# 评价任务重复发布与删除

同一条授课安排（lesson_id）最多保留一个未删除的评价任务。跨班次、跨时间的独立授课即使名称相同，仍属于不同授课，不按课程名称全局去重。

发布时检查所有未删除状态：进行中、待开放、已截止、已关闭、已撤销均阻止重复发布。通过授课事务锁、当前读和数据库唯一占位表共同拦截并发发布；发布失败整体回滚，不留下资格或占位。

“删除”仅对已关闭或已撤销任务开放，保持原维护权限和班次范围；进行中及仅时间截止的任务须先关闭或撤销。点击前确认，删除后从管理列表、人员待评入口及有效统计中移除，旧二维码不可继续使用。数据库保留任务、名单快照、评分与操作审计，并记录删除人和时间，不物理清空答卷。

删除后若该授课仍有历史未删除任务（例如旧版本产生的重复任务），仍不允许再发布；清理多余任务需要逐一确认。所有旧任务都从列表删除后才可重新发布，重新生成令牌与名单快照。历史答卷不自动复制到新任务。

V7迁移不自动关闭、撤销或删除既有重复任务，仅创建占位并启用新规则。请由业务人员确认保留哪份任务，优先保留已收集到有效评分的任务。

前端依状态隐藏无效操作：已关闭不再显示关闭/延期/二维码等入口，已撤销不显示关闭/撤销/纸质补录；维护角色可以直接看到“删除”按钮。后台仍会再次检查状态，不能依靠伪造请求删除运行中任务。
# 自动完成与重复提交

应评人数大于零、且发布时名单中的所有学员均已有有效答卷时，任务自动变为 `COMPLETED`，页面显示“已完成”。在线提交和纸质补录均参与完成判定；最后一份答卷与完成状态在同一事务中保存，并记录 `TASK_COMPLETED` 审计。零人任务不视为完成。

已完成任务不能继续评价、补录、延期、关闭或撤销，仍可查看结果、导出及按权限删除。重复发送已经成功的同渠道提交只返回原回执，不新增答卷，也不修改原评分和意见，以支持网络重试。

V8 数据迁移会将历史未删除、未撤销且已经收齐答卷的任务补记为已完成；已撤销任务保持撤销状态。已完成任务同样阻止同一授课安排重复发布，删除规则与已关闭任务一致。
