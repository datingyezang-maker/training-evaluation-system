# 自有工作台界面

界面使用项目自行编写的HTML、CSS和原生JavaScript，无外部模板CSS、图标字体或在线CDN。恢复原绿色主色#19594e、深绿侧栏、浅灰绿页面背景；通用管理后台的侧栏、顶部工具栏、指标卡、表格和弹窗布局由本项目实现。

样式入口：static/assets/workspace-ui.css，交互入口：static/assets/workspace-ui.js；继续复用本项目已有的业务页面、动态维度表单、权限及接口。

桌面侧栏可以收起，窄屏使用抽屉导航；顶部功能搜索只显示当前角色可以进入的模块。指标、人员和评价结果来自实际API，不加入演示数据。移动评分和个人中心使用各自原有样式。

管理端和手机号登录页的错误提示放在对应表单内，空账号/密码先在前端提示，服务端登录失败信息直接展示；管理请求增加15秒超时，并区分连接失败和非JSON异常响应。错误不回显输入的密码。链接移除下划线，下载入口采用边框按钮，文件选择按钮与表格操作使用原绿色主题。

使用mvn clean package执行干净打包，确保已经删除的静态资源不会留在target/classes或旧JAR中。验证包括业务与安全集成测试、静态资源加载和页面脚本逻辑冒烟。浏览器需要强制刷新以更新旧缓存。
