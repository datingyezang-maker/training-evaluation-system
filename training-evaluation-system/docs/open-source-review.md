## 本轮实现

- 授课发布准备检查：班次、教师、名单人数、已有有效任务数；可直接转入指定授课的发布表单。
- 发布表单显示名单人数和已有任务提示；后续版本已按用户要求禁止同次授课重复发布，详见任务生命周期文档。
- 批量按学号关联班次，1—200人，全部学号存在才写入，重复学号和已关联成员跳过，错误整批回滚。
- 模板评分预览、复制为新版本，复制不改原模板与历史任务。
- 人员提交进度按全部/未提交/已提交过滤；未提交名单Excel导出，不包含评价码、分数或意见。
- 任务延期：仅OPEN状态可操作，新期限须晚于原期限及当前时间，必填原因、记录新旧时间及操作者；不恢复关闭或撤销任务。

以上由本项目独立实现。任意题数问卷、草稿审核流、部门共享范围、自动通知仍属于后续设计范围，不宣称已实现。
