# 自动学号

后台新增学员、学员手机号注册、管理员创建或批量导入学员账号时，系统自动按 `00001`、`00002` 递增分配学号，至少五位，超过 `99999` 后自然扩展为六位。手机仍是登录账号，学号用于档案与名单。

使用数据库持久化序列和事务行锁，不依赖浏览器或进程内计数。重启不重置，删除后不回收；注册等业务失败时随事务回滚。已经存在的相同学号自动跳过，最终仍受数据库唯一约束保护。编辑姓名不修改学号，后台新增不接受客户端自定义学号。

历史档案学号不自动重编号，避免已发放资料、名单和外部记录失配。Excel 导入支持第一列学号留空自动生成、第二列姓名必填；显式填写的历史学号仍保留。文件中的显式学号先入库，再为留空项编号，避免同文件内重号。显式学号含前导零时请使用文本单元格。

升级时 Flyway 执行 V10 建立序列。已有手机号账号绑定现有学员档案时不重新生成学号。
