# 管理端使用体验更新

本轮围绕培训负责人的日常流程调整，不改变现有数据库记录和权限模型。

- 左侧固定导航，登录后默认进入工作概览；按权限展示菜单。
- 概览显示真实班次、授课、进行中任务、有效任务评价完成率；提供流程快捷入口和最近任务。
- 列表统一日期格式和中文角色、状态；评价任务显示应评/已评进度，并支持按实际状态筛选。
- 列表关键字筛选与每页10条分页（当前小规模数据在客户端分页）。
- 班次直接显示负责人姓名和学员人数；名单按姓名/学号搜索添加，逐人移除，不再要求记忆编号。
- 学员提供空白Excel模板下载，继续保留整批校验与事务导入。
- 发布任务预填当前开放时间、一天后的截止时间；新增用户默认业务角色，新模板预填标准维度及等权值。
- 课程二维码可下载，评价链接可复制；提示公共二维码与个人评价码分别发放。
- 结果展示真实维度均分条形图；详情可收起。

候选学员查询要求写权限及班次范围，关键词至少2字符，一次最多50条。不会将全部学员名单直接返回非管理员。

当前已扩展为五种角色和可增删的1—30项评分维度，仍采用一班一个负责人。微信实机与单位现场验收仍需在真实网络和设备完成。
