# 账号审核与维护

用户权限列表显示待审核、通过、驳回状态，以及登录锁定时间。新注册教师进入PENDING，保持停用；管理员核对身份和档案后点击“审核”，填写原因，通过则启用，驳回则保持停用。普通编辑不能直接启用未通过审核的账号。

审核记录保存结果、原因、审核人和时间，同时写操作日志；重复处理已审核账号会拒绝，避免覆盖前次结果。历史账号迁移为APPROVED但保留原启用状态，不把既有停用自动当作待审核。

账号因连续登录错误锁定时，管理员可填写原因解锁；解锁不会启用停用账号，也不会改变审核状态。管理员重置密码要求至少12位、UTF-8不超过72字节，并填写原因；只存BCrypt摘要，清除登录失败次数，旧会话在下次请求失效。操作日志不保存密码。

新增接口均为POST并要求管理员权限与CSRF：

- `/api/business/accounts/{id}/review`：result=APPROVED或REJECTED，reason必填。
- `/api/business/accounts/{id}/unlock`：reason必填。
- `/api/business/accounts/{id}/reset-password`：password、reason必填。

教师个人中心、注册页及手机号登录继续使用原入口。图形验证码不证明手机号归属，本轮未接短信；审核需依托单位实际身份核对。
