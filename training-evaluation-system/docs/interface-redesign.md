# 界面与交互整体升级

## 设计范围

保持#19594e深绿色主色，采用项目自有HTML/CSS/原生JavaScript，所有图标由本项目定义SVG路径，不依赖图片、字体库、UI模板或CDN。

- 导航按工作空间、资源管理和系统设置分组，角色控制可见范围；统一线条图标和选中状态。
- 顶部工具栏保留功能搜索、账号标识、修改密码与退出；主内容独立展示页面标题和层级。
- 工作概览展示真实班次、授课、进行中评价和完成率；最近任务与流程指引分栏呈现，不使用演示趋势或虚构统计。
- 列表统一筛选区、记录数、表头、状态标签和分页；高频操作外，其余操作进入浮动“更多”菜单，避免横向挤满操作链接。
- 详情、延期、人员关联、补录和报告通过右侧抽屉处理，保留当前列表上下文；支持关闭按钮、遮罩和Esc。抽屉提供对话框语义及键盘焦点约束。
- 原生编辑弹窗保留并统一标题、字段、操作区和右上角关闭按钮。评分维度保持可动态增删及排序。
- 控件对齐规则集中在alignment.css：关闭图标以中心定位的几何线条绘制，避免字符基线偏移；图标按钮、头像、复选框、单选框和维度行统一对齐，人员端及H5也同步处理。
- 登录页、个人中心、手机评分同步统一字体、边框、间距、评分选项和错误反馈；人员中心与H5关键样式仍内联交付，保持穿透环境兼容。

## 实现入口

管理端最终设计层为assets/experience.css及experience.js；手机与人员中心为assets/public-ui.css。业务API、数据库结构、评分口径和权限沿用现有实现，本轮不修改数据库记录。

## 验证

业务与安全集成测试、前端DOM逻辑冒烟、资源引用审计，以及本机Chrome桌面1600px和手机390px检查。截图保存在target/ui-*.png，可通过scripts/visual-review.cjs重复检查（需本机Chrome调试端口及测试服务，密码通过UI_REVIEW_PASSWORD提供，不写入文件）。

本轮是界面与交互升级，不以项目金额作为质量或验收保证。微信实机及单位设备的完整流程仍需现场验收。
