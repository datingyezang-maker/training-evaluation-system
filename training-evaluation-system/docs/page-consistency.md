# 页面切换与操作文案一致性

评分模板页面出现“新增学员”、学号表格、学员导入工具并非单个按钮文案错误，而是旧页面异步响应返回后覆盖了新页面。原有部分加载层仅在渲染之后检查版本，无法阻止底层先写入错误内容；导航期间还会直接丢弃后续点击。

所有后台模块统一使用本轮页面加载标识。切换时清空旧表格、工具栏和分页，立即设置目标模块的按钮文字，加载期间禁用新增按钮。列表数据只有在模块及加载标识同时匹配时才能提交给页面。各层的导入、审核、权限、任务按钮在同样检查通过后再追加。

导航接受后续选择，以最后一次选择为准；旧的业务读取与详情请求返回后失效，不能打开旧页面弹窗，也不能把过期错误显示在新页面。写请求不自动取消或重试，仍由后台权限、事务和唯一约束保护。

评分模板显示“新增评分模板”；学员、教师、班次、授课安排各自显示对应新增操作；评价任务显示“发布评价任务”；用户权限模块显示“新增账号”。学员导入仅出现在学员模块，账号导入仅出现在用户权限模块，人员权限设置仅出现在学员和教师模块。

前端冒烟测试遍历全部列表模块，并模拟慢学员请求与失败学员请求，验证切换评分模板、教师后标题、按钮、数据列、导入工具及权限按钮不会被旧响应覆盖。
