# 自定义评分维度

评分模板支持1—30项维度，每项可设置名称及1—100整数权重。通过“新增评分维度”添加，删除按钮移除，上移按钮调整顺序；至少保留一项。名称不能为空、重复或超过80字。每项仍为1—5整数评分。

编辑弹窗右上角“×”、底部取消及Escape均可关闭，未保存的修改不会入库。已用于发布任务的模板保持不可变，需要调整时点击“复制为新版本”，编辑副本后用于新的任务。

维度由 template_dimension 存储，分项答卷由 answer_dimension 存储；各份答卷的加权综合分保存在 answer.total_score。V6迁移将历史模板的三项及已有答卷转为新结构，并按原权重回填综合分；旧字段保留用于兼容，不删除历史评分。

移动H5、个人中心进入的评价、纸质补录、模板预览、任务报告、Excel、PDF、教师/班次统计均采用动态维度或相同综合分口径。新客户端提交 scores 对象，以当前模板维度编号为键；缺项、多项、未知编号、非整数及越界评分均拒绝。旧三项客户端仅兼容恰有三维度的任务。

综合分 = 所有分项分数乘权重之和 / 权重总和，保存六位小数；页面通常显示两位。不同维度数量的课程仍使用相同1—5量表，但合并比较时应由业务方确认维度含义是否可比。

验证包括五维度加权得分、分项明细与Excel表头、非法配置与缺项提交，以及既有评分、安全和权限回归。升级前备份数据库，重启后自动执行迁移。
