# 学员与教师的后台功能授权

更新：教师账号默认拥有班次管理、授课安排和评价任务三项权限，适用于后台创建、导入、自注册及身份转为教师。自注册教师仍需审核才能登录。V11升级一次性补齐已有教师的三项权限；此后管理员主动取消的权限不会在重启或普通编辑时恢复。学员仍需单独授权。提示通知移至右上方，4秒自动清除且不接收鼠标点击，避免遮挡底部操作区。

管理员进入“学员”或“教师”，点击对应行的“权限设置”。身份不变，权限保存在 `account_permission` 表，不使用浏览器本地存储，也不把教师提升为系统管理员。

| 勾选项 | 授权范围 |
| --- | --- |
| 班次管理 | 新增班次，编辑、删除本人负责的班次，选择和移除班次学员 |
| 授课安排 | 在本人负责的班次内新增、编辑、删除授课安排 |
| 评价任务 | 在本人负责的班次内发布、延期、关闭、撤销、删除评价任务，二维码、评价码、进度和纸质补录；仍遵守任务状态限制 |

首次使用建议为培训组织教师勾选全部三项，以便完成完整流程。仅授课安排或评价任务权限的人员，需要管理员先把相应班次的负责人指定为该账号。系统不会因为某人是授课教师就允许其管理他人班次。

获得任一权限后，个人中心显示“进入管理工作空间”，也可直接使用 `/admin/` 登录。同一账号仍可返回个人中心评价课程或查看授课汇总。后台只读依赖数据包括评分模板、教师目录，以及本人负责班次、授课、任务、名单和统计报表；评分模板、人员档案、账号和授权的维护仍只允许管理员。

没有绑定账号时，界面提供“创建登录账号”，预选人员身份及已有档案；需管理员补全手机号和初始密码。此操作不自动生成弱密码。停用、待审核账号即使被授予功能，也不会因此启用或通过审核。

取消全部勾选将取消后台入口。服务端每次请求从数据库检查授权，已有会话不能绕过撤权；界面重新进入或刷新后同步入口。授权人、目标账号和权限项写入操作审计。自注册不能自行赋予功能权限。

升级时由 Flyway 自动执行 V9 建表，现有学员和教师默认没有后台管理权限。管理员、培训负责人和只读角色的既有行为保持不变。
