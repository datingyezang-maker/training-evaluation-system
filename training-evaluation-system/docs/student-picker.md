# 班次学员可视化选择

班次“学员名单”打开抽屉后，自动查询学员表中尚未关联该班次的人员，以姓名首字头像、姓名和学号展示。无需输入学号或编号才能添加。

支持单选、多选、当前页全选、清空选择及姓名/学号筛选。每页100人，翻页或筛选保留已选人员，选中总数实时显示，单次最多200人。切换单选模式会只保留第一位已选人员。全选明确作用于当前页，不会悄悄选择未展示的其他人员。

点击“添加所选学员”后统一提交学员ID，先验证全部记录，再在同一事务内关联；不存在的学员导致整批回滚，重复或已关联人员自动跳过并返回数量。只有管理员与负责该班次的业务人员可以选人，候选接口不返回手机号、账号或密码。

上方保留已关联人员和逐人移除操作。班次名单变动不改变已发布评价任务的应评快照。本轮移除前端手填学号批量关联区域，原兼容API暂保留。

接口：GET `/api/business/classes/{id}/student-picker?page=1&keyword=`；POST `/api/business/classes/{id}/members/select`，JSON字段 `student_ids`。
