# 页面与交互全面排查记录

## 范围

检查后台班次、授课安排、评价任务、统计报表、学员、教师、评分模板、用户权限、操作日志九个模块，以及个人中心、H5评价端。重点排查异步请求顺序、页面及弹窗生命周期、提交目标、重复操作和文案。

## 本次发现及修复

- 同一模块连续查看不同记录：新增独立窗口标识，后打开的记录不再被旧请求覆盖。
- 关闭窗口后请求才返回：关闭抽屉、遮罩、编辑窗口或按Esc会使旧读取失效，防止重新弹出旧内容。
- 编辑窗口选项加载乱序：基础编辑及各扩展层均在等待后核对窗口标识，防止旧表单混入新表单。
- 提交目标依赖当前导航：编辑开始时保存所属模块，提交前核对模块；保存期间拦截再次提交和再次打开编辑。
- 旧记录保存后刷新新页面：人员权限、班次成员、纸质补录、账号操作、任务延期等按窗口标识判断结果是否仍适用于当前界面。删除、导入和模板复制仅在原页面仍有效时刷新。
- 按钮或表单连续点击：通用操作按钮、编辑表单、人员授权、纸质补录及H5评价增加进行中保护。H5成功后不再发送相同评价。
- 业务错误提示误导重试：H5的400等业务错误只显示实际原因，不再统一附加网络重试说明。
- 个人中心加载和验证码刷新：旧一轮个人信息不覆盖新一轮结果；图形验证码加载时不再重复发起刷新。
- 文案核对：新增账号的窗口名称与入口统一为“账号”，评分模板维度、人员权限、导入工具继续按模块隔离。
