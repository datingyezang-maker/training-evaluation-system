# 验收清单与扩展边界

## 当前业务验收步骤

1. 管理员入库初始化，重新启动仍可登录；修改密码后原密码及旧会话不可用。
2. 创建业务人员/只读人员，分配班次负责人；验证跨班次查看、修改、导出被拒绝。
3. 创建教师、学员、班次与授课；Excel 导入重复行时整批回滚。
4. 发布前无名单应报错；发布后成员快照不随班次名单变更。
5. 发布任务并下载二维码、个人评价码；手机在可达网络扫码进入正确课程。
6. 验证提前、截止、关闭、撤销、错误个人码、缺评分、越界分数及重复提交。
7. 检查任务报告、班次/教师汇总、Excel、PDF 中文和纸质补录；纸质与线上不能重复。
8. 检查关键动作审计、生产 MySQL迁移、备份和恢复、实际手机浏览器及微信兼容。

## 当前实现边界

角色固定五种，一班一个负责人；模板支持1—30项自定义维度、各1—5分、支持名称权重与不可变版本；纸表人工补录，无OCR。学员和教师支持手机号账号，绑定手机号的学员必须本人登录评价，历史未绑定资格保留个人码方式。图形验证码不证明手机号持有，未接短信。教师注册进入显式审核，支持审核原因、解锁与密码重置。跨人员共享班次、部门树范围仍待后续设计。

列表适配当前小规模业务，可按关键字筛选，操作日志显示最近100条。大规模数据后续增加服务端分页、条件筛选及长耗时导出任务。无自定义角色权限设计器、部门树隔离、完全匿名协议或问卷拖拽设计器。

## 尚需部署现场完成的验证

单位私有云网络/HTTPS、微信实机、PDF打印效果、200人集中访问和必要的2000人场景、漏洞扫描、单位合规验收、备份恢复。自动化接口测试不等同于已完成上述现场验证。
