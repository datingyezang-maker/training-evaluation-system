# 架构与权限模型

```text
PC 浏览器 / 微信内置浏览器或手机相机扫码
          │ 单位可达网络 + HTTPS
       单位网关 / Nginx
          │ 同源转发
Spring Boot Java8 单体
 ├─ static/admin、static/h5、static/assets：HTML/CSS/JavaScript
 ├─ identity：数据库账号、认证、改密、失败锁定
 ├─ training：班次、教师、学员、授课、模板、任务
 ├─ evaluation：资格验证、事务评分、纸质补录
 ├─ report：二维码、统计、Excel、PDF、名单导入
 └─ audit：基础访问记录与业务审计
          │ JDBC / Flyway
       MySQL 5.7（本地3307）
```

## 持久化结构

`app_user` 保存账号、BCrypt 摘要、角色、启用状态、失败次数和锁定时间；`training_class` 指定负责人；`teacher`、`student` 为基础档案；`enrollment` 为班次学员关联；`lesson` 为具体授课，而不是单独的课程名称。

`evaluation_template` 与 `template_dimension` 保存可变数量的维度名称和权重；`evaluation_task` 绑定授课和模板，含随机公开令牌、开放/截止时间和状态。模板被任务引用后不能修改，可新增模板版本。

`eligibility` 在任务发布时复制名单，每个任务学员一条，带个人随机评价码。`answer` 对资格唯一，保存评分、意见、渠道、回执及纸质补录编号/操作人。移除班次成员不会影响已发布任务的应评名单。

`audit_log` 保存动作、对象、操作者和时间。业务写入与审计在同一事务，失败整体回滚；访问审计为附加记录，写失败记录服务错误，不宣称具备防篡改存证能力。

## 权限矩阵

账号已新增 STUDENT / TEACHER 人员角色：学员只访问本人应评任务，教师只访问本人授课汇总；均不可访问下表的管理接口。手机账号表含唯一手机号及唯一人员档案关联，教师自注册待审核，详见 [手机号账号说明](phone-accounts.md)。

| 能力 | ADMIN | BUSINESS | VIEWER |
| --- | --- | --- | --- |
| 用户与角色分配、基础教师/学员、模板维护 | 全部 | 不可维护 | 不可维护 |
| 班次、授课、任务维护 | 全部 | 本人负责班次 | 不可维护 |
| 班次名单关联 | 全部 | 本人负责班次 | 只读 |
| 课程/教师/模板基础查询 | 全部 | 允许 | 允许 |
| 学员查询 | 全部 | 所负责班次已关联学员 | 所负责班次已关联学员 |
| 结果、统计、Excel、PDF | 全部 | 本人负责班次 | 本人负责班次 |
| 个人评价码、二维码、纸质补录 | 全部 | 本人负责班次 | 不可 |
| 审计日志 | 全部 | 不可 | 不可 |

业务人员新建班次时负责人自动为本人；管理员可指定负责人。只读人员若要查看某班次，需成为该班次负责人（当前一班一个负责人）。跨人员共享班次或部门树范围是后续扩展。

## 评分一致性

提交在事务内锁定任务和资格，重复提交返回原回执，数据库唯一约束作为最终防线。相同资格不得同时出现线上与纸质记录，冲突提示处理，不覆盖原记录。任务关闭后拒绝线上评分，但允许授权补录；撤销后拒绝补录且不能恢复。

成绩 = 所有维度分数乘对应权重之和 / 权重总和。教师/班次汇总按有效答卷加权，未评不计零分；参与率 = 答卷数 / 任务发布时应评人数。统计总览排除撤销任务，仍可在任务明细检查其原始记录。

## 认证

同源 Session、CSRF、HttpOnly、SameSite=Strict；生产 Secure Cookie。角色、启用状态每次请求从库重新核对，改密后旧会话失效。登录错误5次锁15分钟。个人评价码为持有者凭据，不能阻止转借；评价不是完全匿名。
